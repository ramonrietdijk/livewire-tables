# Requirements

Before proceeding, please make sure you have **at least** met the following prerequisites:

::: info
Note that Alpine.js is included in Livewire by default since version 3.
:::

| Requirement  | Version        |
|--------------|----------------|
| PHP          | `^8.3`         |
| Laravel      | `^12.0\|^13.0` |
| Livewire     | `^3.0\|^4.0`   |
| Alpine.js    | `^3.0`         |
| Tailwind CSS | `^4.0`         |
